# 新聞素養助手（News Literacy Assistant）

中央大學 115-1 AI Agent 課程專題。目前處於構想階段（單元 0 發想）。

---

## 動機

假新聞與不實資訊充斥，加上各媒體立場不一，許多人擔心被帶風向而乾脆不看新聞，長期下來反而與世界脫節。另一方面，台灣新聞多以輕鬆、搞笑、無厘頭的風格為主，雖然有趣，但並非真正重要的資訊。

選這個題目的理由，是想藉專題培養自己的**媒體識讀能力**與**國際觀**：

- 媒體識讀——能看出同一件事被不同媒體怎麼包裝
- 國際觀——不要只停留在本地的新聞視角

## 功能構想

- 篩選新聞來源，抓取後統整重點
- 由一則新聞延伸連結到相關新聞，建立事件脈絡
- 附上可供查證的相關連結
- 納入不同國家的報導，比較各國視角

## 預想困難

1. 是否有辦法抓取社群媒體上的文章？
2. 即使抓得到，如何確認是官方發布的資訊？
3. 要如何辨別「中立」的新聞台？

## 設計決策

針對上述困難，構想階段做了以下調整：

### 1. 社群媒體改抓「官方來源」

X / Meta 的 API 目前收費高且限制多，個人專題不可行。改為只抓政府機關、企業官網的 RSS 與新聞稿頁面——「是否為官方」由來源網域直接保證，省去驗證問題。

### 2. 放棄判斷中立，改為多源對照

不由 Agent 認定誰中立。這個判斷很難站得住腳，也容易變成「AI 幫使用者選立場」。

改為同一事件並排呈現 3–5 家不同立場的報導，由 Agent 比對三件事：

- 事實陳述是否一致
- 用詞框架有何差異
- 哪家漏報了什麼

最終由使用者自行判斷差異。這才符合「素養」的定位，也對應培養媒體識讀的初衷。

### 3. 查證串接現成資源

Cofacts（真的假的）有公開 API，台灣事實查核中心、MyGoPen 也有公開內容，比從零自建查證邏輯實際。

### 4. 縮小第一版範圍

先做「單一議題追蹤 ＋ 多源對照 ＋ 查證連結」，不一開始就做全球新聞。國際觀的部分在單一議題內加入 1–2 個外媒來源（如 BBC、Reuters 的公開 RSS），比「搜尋全世界的新聞」可行得多。

## 技術路線（規劃中）

```
RSS 訂閱
  → 全文抽取（trafilatura / newspaper3k）
  → 向量檢索串連相關報導
  → LLM 做摘要與措辭差異比對
  → 附查證連結輸出
```

## 已知風險

最大風險是**資料取得**（來源授權、社群平台封閉）。因此第一版必須把範圍收斂到單一議題，確定跑得動之後再擴充。

備案題目為「英語學習助手」，若新聞來源取得卡住則轉換。
